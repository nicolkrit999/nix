# test-shell-init-syntax

Syntax-lints the shell init code generated by the bash/zsh/fish/atuin/tailscale modules and asserts that exactly one shell is active per platform. It also guards the per-platform bash init split, the rebuild alias texts under `constants.nixImpure` (with nh on and off), the push path of `swboot`, and the git identity / repo-hook wiring.

## Run

From the repo root:

```bash
bash templates/tests/common/test-shell-init-syntax/check-common-shell-init.sh
```

From inside the directory:

```bash
bash check-common-shell-init.sh
```

## How it works

`01-scenario-shell-init.nix` loads the flake (Darwin variants run on `lib/fixture-host-darwin.nix` with only the shell, fastfetch, tailscale, nh, cachix, attic, nix-sweeps, yazi, git and stylix module files added, plus `users/krit/common/toplevel/sops-secrets.nix` (left disabled) as a denix path so every denix pass imports the sops-nix darwin module that attic's `sops.templates` definition needs, and `homebrew.enable` on so `environment.systemPath` gets `/opt/homebrew/bin`; no real host is used) and, per variant, builds `extendModules` with atuin, eza, zoxide and tailscale forced on (plus optional `constants.shell`, `fastfetch.enable`, `nixImpure`, `nh.enable` and cachix push overrides). Each variant yields `checks` (`"ok"` / `"FAIL: ..."`), `files` (rendered HM shell text) and `shAliases` (aliases containing `sh -c`).

`check-common-shell-init.sh` evaluates each variant once, prints one PASS/FAIL line per check, then writes the rendered text to files and runs `bash -n`, `zsh -n` (pinned nixpkgs) and `fish --no-execute` on them. Exits 1 on any failure. When a variant fails to evaluate, it is re-run with `--show-trace`: the FAIL detail lists the `error:` lines plus the innermost trace frames (file and line of the failing expression), and the full trace is kept as test evidence (`keep_evidence`).

Variants: NixOS minimal host x {bash, zsh, fish} x fastfetch {on, off}; minimal bash with nixImpure true (+ cachix push), true with nh off, and false; minimal bash with git wiring twins; Darwin fixture host with the constants default shell and with fish forced; Darwin forced zsh with fastfetch; Darwin forced bash with fastfetch and nixImpure false; Darwin nixImpure true with nh on and off; standalone home (`krit@template-host-minimal` via `homeConfigurations`, `nixImpure` forced true and false; skipped without `nixosConfigurations`).

The `--apple-use-keychain` check applies only to the forced-zsh Darwin variant (it exists only in zsh.nix; the Mac shell is fish), so Darwin bash and fish must not carry it. `tpm-reenroll` is a package, not an alias.

The nh assertion checks read `config.assertions` for the nh.nix message: it must fire exactly when nh is off and nixImpure is false. Each nh-off variant also builds a pure twin (`nixImpure` overridden to false at a priority above the variant's `mkForce`) that must fire it, so a check that never sees the assertion fails. The git checks build `extendModules` twins of the git-wiring variant with forced `gitUserName` / `gitUserEmail` (empty, set, name only) and `flakeDir`, parse the `[user]` section of the generated `git/config`, and read the `setupNixRepoHooks` activation text. The test identity is a dummy (`test@example.invalid`).

## Checks

Per variant (all):

| Check | Expected |
|-------|----------|
| shell-is-X | forced `constants.shell` took effect |
| exactly-one-shell-enabled | enabled of `programs.{bash,zsh,fish}` is exactly `[shell]` |
| integrations-match-shell | atuin/eza/fzf/zoxide/starship/yazi integration flags true only for the active shell |
| integrations-cover-programs | those programs are enabled (guards against vacuous flag comparison) |
| inactive-shells-empty-of-startup | inactive shells contain no uwsm/tmux code |
| tailscale-helpers-in-active-shell | tailscalenodeset/remove defined in the active shell (fish: functions) |
| fastfetch-splash-matches-flag | splash block and splash command present iff fastfetch enabled |
| syntax bash/zsh/fish/fishfn-* | rendered text parses (`-n`) |
| deadnix-unpinned | deadnix aliases follow upstream HEAD (`github:astro/deadnix`, no tag pin) |
| tpm-reenroll-present/absent | package on NixOS only, never an alias |
| nfc-impure-yes/no | Darwin `nfc` has `--impure`, NixOS does not |
| home-impure-true / home-impure-false | (standalone home) `sw`, `gsw`, `swdry`, `upd`, `nfc` contain `--impure` iff `nixImpure` |
| home-hm-gens-untouched | (standalone home) `hm-gens` stays `home-manager generations` |

NixOS variants:

| Check | Expected |
|-------|----------|
| uwsm-start-exactly-once | `uwsm start default` appears once across all shells |
| hyprland-signature-in-active-shell | `HYPRLAND_INSTANCE_SIGNATURE` fix present |
| no-homebrew-on-nixos | no `/opt/homebrew` or keychain text |
| nixos-bash-tmux-display-gated | (bash) tmux autostart is `[ -n "$DISPLAY" ]`-gated `tmux new-session -A -s main`, no `exec tmux` |

Darwin variants:

| Check | Expected |
|-------|----------|
| no-uwsm-or-hyprland-on-darwin | no uwsm / Hyprland text |
| tmux-autostart-execs-on-darwin | always-on `exec tmux` |
| darwin-zsh-keychain-homebrew-on-system-path | (zsh) `--apple-use-keychain` present, no `/opt/homebrew` PATH prepend in the zsh init; `/opt/homebrew/bin` comes from nix-darwin `environment.systemPath` |
| no-homebrew-or-keychain-outside-zsh | (bash, fish) no keychain flag |
| darwin-bash-no-display-gate | (bash) no `$DISPLAY` test in the init (tmux and splash) |

Bash variants (NixOS and Darwin):

| Check | Expected |
|-------|----------|
| bash-sections-unnumbered | no `# <n>.` numbered section comment in the bash init |

Alias variants:

| Check | Expected |
|-------|----------|
| sw-impure-true / sw-impure-false | (NixOS) `--impure` and no `nh os switch` when forced true; the reverse when false |
| impure-rebuild-aliases-no-nh | (NixOS, nixImpure true) sw, swboot, swtest, swdry, swfall, gsw, gswfall, gswoff, swsrc, swoff, tswsrc, upd all run `nixos-rebuild ... --impure`, never `nh os` |
| impure-dry-and-offline-texts | (NixOS, nixImpure true) swdry = `nixos-rebuild dry-build --flake . --impure`; swoff/gswoff = `sudo nixos-rebuild switch --flake . --impure --offline` |
| swpure-pure-nh-on / swpure-pure-nh-off | (NixOS, nixImpure true) swpure is pure: `nh os switch <flake>` with nh on, `sudo nixos-rebuild switch --flake .` with nh off |
| pure-nh-texts-unchanged | (NixOS, nixImpure false) swdry/swoff/gswoff/swpure keep their exact nh texts; swboot starts with `nh os boot`, upd with `nh os switch --update` |
| darwin-impure-rebuild-aliases-no-nh | (Darwin, nixImpure true) sw, swfall, gsw, gswfall, swdry, gswoff, upd run `darwin-rebuild ... --impure`, never `nh darwin` |
| darwin-impure-texts | (Darwin, nixImpure true) sw starts with `sudo darwin-rebuild switch --flake .#<host> --impure`; swdry = `darwin-rebuild build --flake .#<host> --impure --dry-run`; gswoff = the switch command + `--offline` |
| darwin-pure-nh-texts-unchanged | (Darwin, nixImpure false) sw starts with `nh darwin switch`; swdry/gswoff keep their exact nh texts |
| nh-assertion-nhon-impure / -nhoff-impure / -nhon-pure | the nh.nix "nh.enable is false" assertion fires iff nh is off and nixImpure is false (nh off + impure evaluates without it) |
| nh-off-pure-twin-asserts | (nh off) the same variant with nixImpure false fires the assertion (control) |
| push-aliases-use-sh-c | with cachix push forced, an alias contains `sh -c` |
| swboot-pushes-system-profile | (NixOS, push forced) swboot pushes `nix path-info -r /nix/var/nix/profiles/system`, sw pushes `/run/current-system`, never the other |
| syntax alias X (sh -c) | each such alias passes `bash -n` |

Git wiring variant (NixOS minimal):

| Check | Expected |
|-------|----------|
| git-identity-empty-omitted | empty `gitUserName` / `gitUserEmail` write no `name` / `email` under `[user]` |
| git-identity-set-written | non-empty constants write `name = "<name>"` and `email = "<email>"` |
| git-identity-per-key | name set, email empty: `name` written, `email` omitted |
| git-hooks-default-flakedir | `setupNixRepoHooks` tests `$HOME/<flakeDir>/.git` and runs `git -C "$HOME/<flakeDir>" config core.hooksPath .githooks` |
| git-hooks-follow-flakedir | with `flakeDir` forced to `src/flake-under-test` the hook uses that path and no longer names `$HOME/nix` |
