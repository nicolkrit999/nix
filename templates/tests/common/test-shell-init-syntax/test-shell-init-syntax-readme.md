# test-shell-init-syntax

Syntax-lints the shell init code generated by the bash/zsh/fish/atuin/tailscale modules and asserts that exactly one shell is active per platform.

## Run

From the repo root:

```bash
bash templates/tests/common/test-shell-init-syntax/check-common-shell-init.sh
```

From inside the directory:

```bash
bash check-common-shell-init.sh
```

## How it works

`01-scenario-shell-init.nix` loads the real flake and, per variant, builds `host.extendModules` with atuin, eza, zoxide and tailscale forced on (plus optional `constants.shell`, `fastfetch.enable`, `nixImpure` and cachix push overrides). Each variant yields `checks` (`"ok"` / `"FAIL: ..."`), `files` (rendered HM shell text) and `shAliases` (aliases containing `sh -c`).

`check-common-shell-init.sh` evaluates each variant once, prints one PASS/FAIL line per check, then writes the rendered text to files and runs `bash -n`, `zsh -n` (pinned nixpkgs) and `fish --no-execute` on them. Exits 1 on any failure.

Variants: NixOS minimal host x {bash, zsh, fish} x fastfetch {on, off}; minimal bash with nixImpure true (+ cachix push) and false; real nixos-desktop; real Darwin host (fish); Darwin forced zsh with fastfetch.

The `--apple-use-keychain` check applies only to the forced-zsh Darwin variant (it exists only in zsh.nix; the Mac shell is fish). `tpm-reenroll` is a package, not an alias. Darwin with bash is not covered: bash.nix has no platform split (known inconsistency, not a supported combination).

## Checks

Per variant (all):

| Check | Expected |
|-------|----------|
| shell-is-X | forced `constants.shell` took effect |
| exactly-one-shell-enabled | enabled of `programs.{bash,zsh,fish}` is exactly `[shell]` |
| integrations-match-shell | atuin/eza/fzf/zoxide/starship/yazi integration flags true only for the active shell |
| integrations-cover-programs | those programs are enabled (guards against vacuous flag comparison) |
| inactive-shells-empty-of-startup | inactive shells contain no uwsm/tmux code |
| tailscale-helpers-in-active-shell | tailscalenodeset/remove defined in the active shell (fish: functions) |
| fastfetch-splash-matches-flag | splash block and splash command present iff fastfetch enabled |
| syntax bash/zsh/fish/fishfn-* | rendered text parses (`-n`) |
| deadnix-pinned | deadnix aliases reference `deadnix/v1.3.2` |
| tpm-reenroll-present/absent | package on NixOS only, never an alias |
| nfc-impure-yes/no | Darwin `nfc` has `--impure`, NixOS does not |

NixOS variants:

| Check | Expected |
|-------|----------|
| uwsm-start-exactly-once | `uwsm start default` appears once across all shells |
| hyprland-signature-in-active-shell | `HYPRLAND_INSTANCE_SIGNATURE` fix present |
| no-homebrew-on-nixos | no `/opt/homebrew` or keychain text |

Darwin variants:

| Check | Expected |
|-------|----------|
| no-uwsm-or-hyprland-on-darwin | no uwsm / Hyprland text |
| tmux-autostart-execs-on-darwin | always-on `exec tmux` |
| darwin-zsh-homebrew-and-keychain | (zsh) `/opt/homebrew/bin` and `--apple-use-keychain` present |
| no-homebrew-or-keychain-outside-zsh | (fish) no keychain flag |
| syntax sys-zsh | (fish host) system zsh `exec fish -l` snippet parses |

Alias variants:

| Check | Expected |
|-------|----------|
| sw-impure-true / sw-impure-false | `--impure` and no `nh os switch` when forced true; the reverse when false |
| push-aliases-use-sh-c | with cachix push forced, an alias contains `sh -c` |
| syntax alias X (sh -c) | each such alias passes `bash -n` |
